# TaskTracker-

Sobre o projeto

O TaskTracker é um sistema desenvolvido para auxiliar na organização e no acompanhamento de tarefas do dia a dia. O projeto tem como objetivo permitir que o usuário cadastre, visualize e acompanhe suas tarefas de forma simples e organizada.

Funcionalidades
Cadastro de tarefas;
Definição de prioridade: Alta, Média ou Baixa;
Definição de data limite;
Visualização das tarefas cadastradas;
Identificação das tarefas pendentes e concluídas;
Marcação de tarefas como concluídas.
Tecnologias

O projeto será desenvolvido utilizando:

Python;
Git;
GitHub.
